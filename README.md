# Gold Bhishi

Android app to track a Gold Bhishi: monthly installment, 22K/24K gold, grams bought,
value today and profit or loss. Data is stored on the phone; Backup tab shares/restores a backup.

## Get the APK
1. Open the **Actions** tab on GitHub, pick the latest **Build APK** run.
2. Download **gold-bhishi-apk** from Artifacts (a zip), unzip it, and install `app-debug.apk` on the phone.
   Allow "install unknown apps" when Android asks.

Or open this folder in Android Studio and use Build > Build APK(s).
